miga-server

Your own sync server

To share books and the shopping list with your family, Miga connects to a server you host yourself. It's lightweight, runs on Docker and comes with a full admin website.

  1. Start the serversave the docker-compose.yml below, replace the admin token with a long random string (for example, the output of openssl rand -base64 32) and run docker compose up -d.
  2. Create a shared spacein the web admin (http://your-server:8080/ui), create a namespace (say, “home”) and a token for each phone.
  3. Connect the appin Settings › Sync server, add the connection. The rest of the family joins by scanning a QR code.
See miga-server

docker-compose.yml · That file is all you need: the image has everything inside and the data lives in the miga-data volume.

services:
  miga-server:
    image: ghcr.io/calamares00/miga-server:latest
    restart: unless-stopped
    ports:
      - "8080:8080"
    environment:
      MIGA_ADMIN_TOKEN: "replace-with-a-long-token"
    volumes:
      - miga-data:/data

volumes:
  miga-data:

The admin website

Private spaces

each namespace is shared by the phones you choose, with one revocable token per device.

Reliable sync

books, recipes, photos and lists, last edit wins even when clocks disagree.

Web admin

edit recipes in a spreadsheet-like table, change many at once or use the full editor.

PDF from the browser

download a recipe or a whole book with the app's design, in English or Spanish.

Automatic backups

a daily backup with rotation, plus one-click backups and downloads.

No external dependencies

one Docker image with SQLite; put it behind a TLS proxy to use it away from home.
